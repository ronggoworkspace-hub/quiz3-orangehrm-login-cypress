# Quiz 3 Cypress OrangeHRM Login

Project automation testing fitur login website OrangeHRM menggunakan Cypress.

## Website Under Test
https://opensource-demo.orangehrmlive.com/web/index.php/auth/login

## Test Cases
1. Login berhasil dengan username dan password valid
2. Login gagal dengan username benar dan password salah
3. Login gagal dengan username salah dan password benar
4. Login gagal dengan username benar dan password kosong
5. Login gagal dengan username kosong dan password benar
6. Login gagal dengan username kosong dan password kosong
7. Login gagal username berisi spasi
8. Login gagal password berisi spasi
9. Login gagal password berisi huruf kapital
